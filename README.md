# sistem-panen-Nuri
Program sederhana berbasis Python untuk mencatat dan menghitung total hasil panen dari beberapa petak lahan, serta menghitung diskon penjualan hasil panen. Proyek ini dibuat sebagai tugas mata kuliah Algopro dan mendemonstrasikan penggunaan Git untuk kontrol versi dalam kerja tim.
Pastikan Python 3 sudah terinstall di komputer Anda.
Clone repositori ini:
   git clone https://github.com/username/sistem-panen-nama_anda.git
Masuk ke folder proyek:
   cd sistem-panen-nama_anda
Jalankan program:
   python panen.py
